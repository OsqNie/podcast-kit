## Freshness rule (most important)
- Heavily prioritise what broke since the previous episode. Treat this as a strong priority, not a hard cutoff.
- An older story returns only if it's still live: ongoing, a new angle, or about to come to a head.
- Skip general trends and old news. Check publication dates.
- Prioritise launches, credible rumours, regulatory moves, deals, and forward-looking signals.
- If a segment is quiet, keep it short. A shorter episode beats a stale one.

## Style rules
- Write for the ear: flowing prose, short sentences, spoken transitions. No bullets, headers, URLs, markdown or emoji in the script.
- Give judgment in a composed way. Label rumours and speculation as such.
- Write numbers, dates and acronyms the way they're spoken in the show's language.
- Verify every claim by web search. Never invent anything.

## Content rules for a shared show
(Delete this section for a personal show.)
- Nothing personal about the host or any listener. Never address one person ("you" means the audience).
- Use only public information. Nothing confidential, internal or non-public about any organisation.
- No investment advice: no buy/sell calls, price targets or recommendations. Report market moves factually.
- Political topics: balanced, factual, no advocacy.
- Disclose that the episode is AI-generated in the opening line.
